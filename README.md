> Ниже описаны команды к Агенту, в результате которых было создано приложение (без программирования)

## Команда 1

```
Разверни базовое приложение NextJS в корне проекта
```

## Команда 2

> Здесь я в ручную добавил файл `.vscode/extensions.json` и `.vscode/settings.json` для удобного редактирования

```
1. Удали из гит игнора папку с vscode, добавь эту папку репозиторий
2. Удали команду линтирования в package.json и упомиинание в документтции
3. Исправь в документации версиюю NextJS и обнови структуру проекта
4. Добавь в @KODA.md пункт Тестирование и напиши правило, что тестирование не требуется
```

## Команда 4

```
1. Скорректируй код приложения и согласно этим правилам:
- CSS-modules: Используйте \*.module.css для автоматической изоляции стилей, чтобы избежать конфликтов имен.
- CSS-in-JS (Styled Components): Компонентный подход: стилизуйте компоненты, а не элементы, для чистого разделения логики и оформления.
- Избегайте inline-стилей: Используйте только для динамических значений (например, color: props.color).
- Переменные: Применяйте CSS-переменные для тем и переиспользуемых значений.
2. Добавь эти правила в в раздел Стандарты кода
```
