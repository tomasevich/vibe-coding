# Правила проекта

## Стандарты кода

- Используем `TypeScript` строгую типизацию
- Именование: `camelCase` для переменных, `PascalCase` для компонентов

## Структура проекта

- `KODA.md` описанине правил агента
- `README.md` описание репозиторрия

## Архитектура

- Не определена

## Тестирование

- Не требуется

## Коммиты Git

- Формат коммитов: `type(scope): description`
- type: feat, fix, docs, style, refactor, test, chore
- scope: (component|service|utils|etc)
- description: описание изменения на английском языке

## Алгоритм агента

1. Проанализируй запрос
2. Предложи оптимальное решение
3. Внеси изменение в код
4. Добавь коммит GIT
