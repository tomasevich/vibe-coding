## Сборка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен-сервера
npm start

npm run test

npm run test:watch

# Запуск тестов с покрытием
npm run test:coverage
```

## Правила разработки

### Стандарты кода

- Используем `TypeScript` строгую типизацию
- Именование: `camelCase` для переменных, `PascalCase` для компонентов

### Форматирование

- **Prettier**: Используйте `prettier` для форматирования кода (настройки в `.prettierrc`)
- **Полутолы**: Отсутствуют (`semi: false`)
- **Кавычки**: Одинарные (`singleQuote: true`)
- **Точка с запятой в стрелочных функциях**: Отсутствует (`arrowParens: avoid`)
- **Максимальная длина строки**: 80 символов (`printWidth: 80`)
- **Запятые в конце**: Отсутствуют (`trailingComma: none`)
- **Отступ**: 2 пробела (`tabWidth: 2`)

### Стилизация

- **TailwindCSS**: Используйте утилитарные классы Tailwind для быстрой верстки
- **SCSS**: Используйте SCSS для предпроцессинга стилей (переменные, вложенность, миксины)
- **CSS Modules**: Используйте `*.module.scss` для автоматической изоляции стилей компонентов
- **Избегайте inline-стилей**: Используйте только для динамических значений (например, `color: props.color`)
- **Переменные**: Применяйте SCSS-переменные и CSS-переменные для тем и переиспользуемых значений

### Архитектура

- App Router (NextJS 16)
- Server Components по умолчанию

## Тестирование

- Требуются unit-тесты для всех компонентов
- Использовать Jest и React Testing Library
- Запускать тесты перед каждым коммитом: `npm run test`
- Покрытие кода должно быть не менее 80%

### Правила выполнения агента

> Если тесты не проходят, завершить работу и предоставить отчет об ошибках:
>
> 1. Перечислить неудачные тесты
> 2. Указать ожидаемое и фактическое поведение
> 3. Предложить исправления

## Коммиты Git

- Формат коммитов: `type(scope): description`
- type: feat, fix, docs, style, refactor, test, chore
- scope: (component|service|utils|etc)
- description: описание изменения на английском языке в нижнем регистре (lower case)
